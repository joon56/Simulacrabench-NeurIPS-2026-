## Source and protocol checks

The official [2023 SIPP release](https://www.census.gov/data/datasets/2023/demo/sipp/2023-data.html), [dictionary](https://www2.census.gov/programs-surveys/sipp/tech-documentation/data-dictionaries/2023/2023_SIPP_Data_Dictionary.pdf), and [Users' Guide](https://www2.census.gov/programs-surveys/sipp/tech-documentation/methodology/2023_SIPP_Users_Guide_AUG26.pdf) support the channel and key definitions documented in `metadata-review.md`. Local release and schema SHA256 match both `pre-run.json` and `data-audit.json` (`9c5363d56aca2041db20d46d17b81e9be931eb5b18bd5f5238b367d2dd7fb74b` and `a1985e1a6dcc8006521bdf22c7ffd36f37f752921b59972f2dbdeb6cd6328113`). The preregistered script hash also matches the reviewed script and result (`d703a360a4be6456ceabdc807aa2d142e3fa2f9e764f9c87d34fdb949c4f5a38`). Selected columns were recorded before CSV parsing. No response extract is included in this report.

The script selects `MONTHCODE=12`, uses `THHLDSTATUS in (1,2)` and `TAGE_EHC>0` for eligibility, and rejects blank or duplicate `(SSUID,PNUM,MONTHCODE)` keys in every chunk and across chunks. It retains only one month-12 record per person; 476,744 source rows yielded 39,513 month-12 rows, 39,131 eligible persons, and 3,593 with `THOSPNIT>0`. The person-month repetition summary includes 39,250 persons with 12 records, so month selection prevents substantial copied-outcome duplication. The script fixes person and `SSUID` group role hashes with separate namespaces; the group-role overlap count is zero. All five roles have eligible and hospitalized members under both splits. These checks support partition mechanics, not untouched-population claims after inspecting aggregate labels.

## Public missing semantics and output encoding

The dictionary's `.N`/`N` missing-code note applies to **internal** data; the public CSV must be interpreted empirically. Here, `AHREASON=0` occurs for exactly 35,538 eligible persons, and every one of the six reason columns is blank for exactly those persons. The other 3,593 persons have `AHREASON` values 1/2/3 and only documented `1=Yes` or `2=No` reason values. `THOSPNIT=0` also occurs exactly 35,538 times, and all positive parents have answered reasons. Thus blank plus flag 0 is supported as this block's public not-in-universe sentinel; no in-universe blank is silently converted. All eligible parent values are valid `0..365`; invalid-parent, ambiguous-reason, and invalid-reason counts are zero. The parent-zero/answered-child, parent-positive/blank-child, and parent-positive/all-No contradiction counts are each zero. The last check is descriptive; no rule requiring a Yes response was imposed.

Imputed records remain included: `AHOSPNIT` has 34,234 reported, 4,888 statistical-imputed, and 9 logical-imputed eligible values; `AHREASON` has 3,238 reported, 346 statistical-imputed, and 9 logical-imputed hospitalized blocks. These flags are used only to audit encoding, not as GIVEN inputs. The fixed PREDICT parent coarsens `THOSPNIT` into zero versus at least one night, followed by six separate binary reason items. This matches the documented single-parent universe while losing duration information. It should not be mistaken for six mutually exclusive reasons.

## GIVEN and scope checks

All six proposed GIVEN fields pass the script's observed usability threshold, and its exact-copy scan found no candidate equal to a varying target across comparable records. Metadata confirms these are person demographics, rather than hospital target recodes or household-copied outcomes. An independent aggregate read of the restricted month-12 extract checked the two age-limited inputs: all 5,598 eligible people with `TAGE<15` have blank `EEDUC` and `EMS`; all 33,533 with `TAGE>=15` have both answered. Their blanks therefore follow the documented age universes exactly in this release. `TAGE` is interview age; the eligible-population age test correctly uses month-12 `TAGE_EHC`. Identifiers, `THHLDSTATUS`, flags, and hospital summaries remain outside GIVEN.

The channel meets the preregistered `>=5,000` eligible, `>=200` hospitalized, `>=4` usable GIVEN, complete output encoding, unique-key, and no-direct-copy gates. This PASS authorizes only the next preregistered scoped oracle/proxy experiment. It does not claim that exact SIPP gating predicts approximate ERPIS gates, that SIPP resembles UNHCR respondents, or that any learned method improves competition skill. The audit script does not itself construct masked respondent frames; whole-output-block masking and equal held-out fits remain requirements of the subsequent adapter/oracle implementation.
