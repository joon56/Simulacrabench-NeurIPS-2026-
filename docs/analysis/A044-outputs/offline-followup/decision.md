# S0 — Codabench 접속 장애 중 우선 작업

2026-10-23 KST. **RECOMMEND_SEPARATE_S3_E025_PROVENANCE_COMPLETION**.
Codabench 접속 불가는 사용자 보고다. 전체 장애 범위·복구 시각·일정 연장·slot 보상을
독립 확인하지 않았다. 장애를 새 권한이나 기한 변경으로 해석하지 않는다.

확인된 준비 과제 중 최우선은 **E025의 phase2 modular source와 현재 보존 ZIP의
공식 raw 출력 연결 보완**이다. S3가 특정한 gap이며 E064 결과/서버 접속에 의존하지 않는다.
완료하면 E025를 실제 전달 가능한 대안으로 남길 수 있는지 판단이 바뀐다. 점수 상승이나
우승 확률을 직접 추정하는 연구는 아니지만, 최종 대안의 기술적 불확실성을 줄인다.

대안 비교:

- E025 gap 보완: 구체적인 누락 증거, 기존 모델·로컬 환경·고정 입력, 유한한 두 실행으로
  판정 가능. E025를 결국 선택하지 않으면 직접 효용은 작지만, fallback을 유지하는 현재
  전략에는 의미가 있다. 기존 전체 검증을 반복하는 과제가 아니다.
- 방법 문서: 초안의 표현·표·편집 준비는 가능하다. 최종 license 결정·현 Terms가 없어
  지금 제출용 최종 PDF라고 확정할 수는 없다. 기술 작업 뒤 다음 문서 단계로 둔다.
- 새 모델: 서버 장애만으로 새로운 기전·oracle·판독 가치는 생기지 않는다. 현재 즉시
  실행 가능한 두 번째 후보가 확인되지 않았으므로 batch 수를 채우지 않는다.
- A039/A040: 새 명세·수리 근거 없이 HOLD를 풀거나 기존 진단을 반복하지 않는다.
