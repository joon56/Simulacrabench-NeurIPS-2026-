# Historical plans

Dated files here preserve the scope and intended steps of earlier sessions.
They are not a current queue or standing permission to fit, regenerate a tree,
commit, push or resume TEST work. Do not rewrite them to match newer policy.

Start with [status](../status.md), [workflow](../workflow.md) and the task's
current handoff. New sessions use [session prompts](../session-prompts.ko.md).
The [Codex setup guide](../codex-setup.ko.md) covers environment migration.
