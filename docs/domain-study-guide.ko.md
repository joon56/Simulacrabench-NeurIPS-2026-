# 도메인 공부 가이드 (한국어) — domain.md 실행판

[[domain]]의 한국어 학습 가이드. 원문(영어)이 canonical — 서지·링크는 원문 참조.
이 문서는 "무엇을, 어떤 깊이로, 어떤 산출물을 남기며 읽나"를 정한다.

## 0. 총론 — "논문을 순서대로 정독"은 틀린 방법

이 리스트는 ~40편. 전부 정독하면 대회가 끝난다. 원칙 4개:

1. **실험이 논문을 부른다.** E003(soft gating)을 시작하면 그때 §9.1과 Chen &
   Goodman을 읽는다. 읽기가 실험을 만드는 게 아니라 실험 큐가 읽기 큐를 만든다.
2. **논문당 산출물 1개.** 코드 조각, 실험 파일의 설계 결정 한 줄, 또는 이 문서에
   추가하는 요약 3줄. 산출물 없는 읽기는 안 한 것과 같다 (discipline rule 6과 동일).
3. **3-pass 읽기** (Keshav): ① 초록+그림+결론 5분 → 버릴지 결정. ② 본문 훑되
   증명 건너뜀 30분 → 아이디어 추출. ③ 재현 수준 정독 — **구현할 논문에만**.
4. **티어를 지킨다.** 아래 각 문항에 붙인 티어:
   - **[구현]** = 3-pass 전부. 수식을 코드로 재현. 4~5편뿐.
   - **[설계]** = pass 2까지. 특정 섹션만. 설계 결정에 인용.
   - **[스킴]** = pass 1만 (15~30분). "이런 게 있고 왜 안 쓰는지"를 알기 위함.
   - **[사전]** = 통독 금지. 필요할 때 해당 장만 찾아 읽는 참고서.

주간 리듬: 실험 코딩 중심, 읽기는 하루 1~2편 pass 1–2, [구현] 정독은 주 1편.

## §3. Proper scoring rule과 캘리브레이션 ← **최우선 (메트릭 그 자체)**

> 리더보드 = log score. 유일한 local strictly proper rule. 과신한 오답을 무한히
> 벌하고(플로어 덕에 −6.9 nats로 캡), 진짜 믿는 분포를 내는 게 기대점수 최적.
> 0.01→0.05로 올리면 +1.6 nats, 0.9→0.99는 +0.1 — 비대칭. 헤지가 이긴다.

- **3.1 Gneiting & Raftery 2007** [설계] — proper rule 이론의 결정판.
  공부법: §1–2(정의·특성화)와 log score 항목만. 증명 스킵. 산출물: "왜 최적
  제출 = 진짜 사후분포인가" 3줄 요약. 90분.
- **3.2 Guo et al. 2017 (temperature scaling)** [구현] — 현대 신경망은 과신,
  스칼라 온도 하나로 복구. 공부법: 방법 섹션만 정독 후 **20줄 구현**(held-out
  log-loss 최소화하는 T 피팅)을 src/eval에 넣어둠. 모든 학습 모델의 출구에 붙일
  부품. 2시간.
- **3.3 Kull et al. 2019 (Dirichlet calibration)** [설계] — 클래스별 미스캘리브
  레이션엔 온도 하나로 부족. 공부법: temperature가 underfit할 때만 소환. 지금은
  pass 1만. 30분.
- **3.4 Chen & Goodman 1996 (smoothing)** [구현] — 카운트 모델 스무딩의 실증
  플레이북. add-one은 나쁘고 하위분포와의 보간(Jelinek–Mercer)이 강하다.
  공부법: §2–3만. 산출물: 우리 backoff 사다리(stratum→marginal→uniform)의
  보간 가중치를 held-out으로 튜닝하는 코드 — E004+ 재료. 2시간.

## §9. 런칭 후 우선순위 (08-19) ← **§3 다음으로 먼저**

- **9.1 근사 gate = 추정 구조** [구현·논문 아님] — unhcr gate 일치도 중앙값
  0.83. hard coupling은 17%에서 −6.9 nats. 공부법: 논문 없음. 설계 노트 자체를
  읽고 E003으로 구현: 가시 행에서 item별 일치율 → beta-binomial 수축 → 혼합
  가중치. 이것이 첫 번째 새 실험.
- **9.2 RPIS 공개 라운드** [설계·데이터 읽기] — UNHCR 악기 = Enhanced RPIS.
  공부법: 논문 읽듯 말고 **집계표 추출 작업**으로: 9차(2024)·flash(2025)·ERPIS
  보고서(2025.9) PDF에서 문항별 분포표를 CSV로 옮김 → bundled_artifact 형태의
  prior 파일. 산출물 = 데이터 파일 + 출처 기록(method 공개 의무). 반나절.
- **9.3 wave 조건화** [구현·논문 아님] — 59개 multi-select의 라운드 confound.
  sentinel rate를 wave로 조건화. E00X 한 줄 설계.
- **9.4 캡 제거 후 제출 정책** [스킴] — §8.2와 같이 읽음. 아래 참조.

## §1. IRT — 잠재특성 응답 모델

> 응답행렬의 생성 스토리. GRM(순서형)·Bock nominal(무순서)·GPCM이 문항형별
> 카테고리 우도를 줌. 행렬분해와 같은 것(§1.5)이 핵심 통찰.

- **1.1 Samejima 1969 (GRM)** [설계] — 순서형 Likert의 기본 우도. 공부법: 모델
  정의(누적 2PL 경계curve 차분)만 이해하면 끝. 원논문 정독 불필요 — 아무 IRT
  교재 GRM 장이 더 빠름. 산출물: GRM 확률식 1개를 torch로 10줄. 1시간.
- **1.2 Bock 1972 (Nominal)** [설계] — 무순서 카테고리 = 잠재특성 위 softmax.
  공부법: "우리 모델 head는 intercept+slope softmax"라는 결론만. NA_GATED를
  하나의 nominal level로 두는 근거. 30분.
- **1.3 Wu et al. 2020 (VIBO, amortized IRT)** [구현] — 인코더가 응답→능력
  사후분포. HMC 정확도, 수백 배 빠름. 공부법: 모델·ELBO 섹션 정독 + 공개 코드
  훑기. 우리 잠재요인 모델의 뼈대 후보. 산출물: 사후 불확실성이 예측분포에
  들어가는 경로 요약 + 프로토타입 계획. 3시간.
- **1.4 py-irt / torch_measure** [코드 읽기] — 논문 대신 API. 공부법:
  torch_measure의 polytomous 지원 여부부터 실물로 확인(§8.5), 없으면 py-irt.
  1시간 코드 탐색.
- **1.5 Bergner 2012 (IRT=MF)** [스킴] — IRT는 logistic link 저랭크 분해.
  §1과 §2를 하나로 묶는 면허장. pass 1이면 충분. 20분.
- **1.6 Muraki 1992 (GPCM)** [스킴] — GRM의 인접카테고리 대안. 캘리브레이션이
  다를 수 있으니 A/B 후보로만 기억. 20분.

## §2. 저랭크 행렬완성

> 같은 문제의 다른 프레임. 범주형이므로 finite-alphabet 완성(≈다항 우도 +
> nuclear norm)이 직접 해당 — 결국 §1과 수렴.

- **2.1 Davenport 2014 (1-bit)** [스킴] — 이진 관측 저랭크 복원 이론. 목적함수
  = trace-norm 정칙 log-loss라는 사실만. 20분.
- **2.2 Lafond 2014 (finite alphabet)** [설계] — 이 태스크와 이론적으로 가장
  가까움(범주형+우도+log-loss). 공부법: 문제 설정과 목적함수만 정독, 복원
  정리는 스킵. 산출물: 우리 lowrank 모델 목적함수 확정 한 줄. 1시간.
- **2.3 Candès & Recht 2009** [스킴] — 고전 정리. 언제 완성이 잘 되는가 감만.
  whole-respondent 마스킹은 uniform sampling 가정 위반이라는 경고가 수확. 15분.
- **2.4 softImpute** [코드 읽기] — 빠른 실수값 baseline. 논문 말고 sklearn/
  fancyimpute 구현으로. 원핫→SVD→정규화 sanity check용. 30분.
- **2.5 mice** [스킴] — 고전 통계 베이스라인. FCS(각 문항을 나머지로 회귀)
  멘탈모델만. 20분.
- **2.6 missForest** [스킴] — RF 반복 대치. RF 투표확률은 미캘리브 —
  §3 재캘리브레이션 필요 사례로 기억. 15분.

## §4. 딥 생성 대치 모델 ← **읽는 목적이 "면역"**

> 벤치마크 증거: 튜닝된 단순 방법이 딥 생성 대치와 대등 이상, GAN은 불안정.
> phase 2 후보로만, 로컬에서 이기면.

- **4.4 Jäger 2021 (벤치마크)** [설계] — **이 섹션에서 이것부터.** 69개 데이터
  결과표만 정독. "딥은 증명 후 채용" 원칙의 실증 근거. 1시간.
- **4.2 MIWAE** [설계] — 유일하게 우도로 학습, p(missing|observed)가 곧 제출
  분포. 딥 업그레이드 1순위. ELBO 섹션 pass 2. 1.5시간.
- **4.1 TabDDPM** [스킴] — multinomial diffusion. 샘플링 기반 분포추정은
  log-loss 비싸다는 점만. 20분.
- **4.3 GAIN** [스킴] — 역사적 베이스라인. 우도 없음, 불안정. 안 쓰는 이유를
  말할 수 있으면 끝. 15분.

## §5. 서베이 방법론 ← **읽기보단 어휘 장착**

- **5.1 Rubin 1976** [설계] — MCAR/MAR/MNAR과 ignorability. 공부법: 정의부만.
  산출물: "NA_GATED는 결측이 아니라 gate의 결정함수, nonresponse level은
  MNAR 가능" 구분을 preprocess 주석에 명문화. 1시간.
- **5.2 Little & Rubin** [사전] — 통독 금지. 논쟁 생길 때 해당 장만.
- **5.3 Groves et al.** [사전] — routing/universe 어휘용. 스킵 패턴 장만.
- **5.4 de Leeuw 2005 (mode effects)** [스킴] — 국가=모드=응답스타일 시프트
  → 국가를 1급 조건 변수로. unhcr가 CATI 단일 모드임은 확인됨(wave가 대신
  중요). 20분.

## §6. LLM 서베이 시뮬레이션 ← **"왜 안 되는가"를 아는 게 목적**

> 결론 먼저: 페르소나 프롬프팅 원샷은 log-loss에 불리 (순서 편향, 과예리
> 분포). 유효한 사용법은 ① 옵션 텍스트 prior를 backoff 밑바닥으로(§8.4),
> ② 분포 매칭 파인튜닝(6.6/6.7), ③ 명시적 분포 발화 유도(6.5).

- **6.1 Dominguez-Olmedo 2024** [설계] — 순서편향 제거하면 균등분포로 붕괴.
  LLM 컴포넌트의 옵션 순서 랜덤화가 필수인 이유. 결과 그림 중심 pass 2. 1시간.
- **6.2 Santurkar 2023 (OpinionQA)** [스킴] — 인구통계 스티어링으로 갭 안
  닫힘. 30분.
- **6.3 Argyle 2023 (silicon sampling)** [스킴] — 낙관론 원조. 상관 fidelity는
  생존, 캘리브 분포 fidelity는 사망 — 6.1/6.2와 세트로. 30분.
- **6.4 Tjuatja 2024 + Bisbee 2024** [스킴] — LLM은 인간 응답편향(묵종·극단화)
  재현 실패 + 페르소나 분포는 과예리(log-loss 최악 실패형). 30분.
- **6.5 Meister 2025** [설계] — 분포 추출 방식이 성능 좌우: 토큰확률 < 명시적
  분포 발화. LLM 쓸 경우의 추출 프로토콜. 1시간.
- **6.6 Cao 2025 / 6.7 Suh 2025 (SubPOP)** [설계] — 분포매칭 파인튜닝은 통함,
  미본 문항 일반화가 한계. phase 2에 LLM 파인튜닝 갈지 결정할 때 정독. 지금은
  pass 1. 각 30분.
- **6.8 묶음 (Huang/Choi/Park/Kim&Lee)** [스킴] — Huang(LLM prior의 유효표본
  크기 = ALPHA 정하는 프레임)만 나중에 승격 가능. 총 30분.

## §7. 대회 모양에 맞는 기계 (08-11 보강)

- **7.1 MRP (Park·Gelman·Bafumi 2004)** [구현] — held-out 응답자 = GIVEN 셀.
  계층 부분풀링이 empty-cell fallback의 원리적 해법. 공부법: 모델 구조만 정독,
  Stan 재현 불필요 — 우리는 계층 스무딩 카운트로 근사. 산출물: E00X
  (GIVEN-stratum backoff)의 풀링 구조 설계. 2시간.
- **7.2 Rendle FM 2010** [설계] — cold-start를 feature 잠재요인으로. lowrank가
  미본 응답자를 못 다루는 문제의 표준 다리. 모델식만. 45분.
- **7.3 Niculescu-Mizil & Caruana 2005** [스킴] — 어떤 분류기가 확률을 제대로
  내는가: RF/NN은 그럭저럭, 부스팅·NB는 왜곡. GBDT 쓰면 재캘리브 필수. 30분.
- **7.4 TabPFN v2** [설계+실험] — 논문 반, 실험 반. 공부법: 샌드박스에서 직접
  돌려봄(행 제한, 다클래스, NA_GATED 처리) — 읽기보다 측정. 반나절.
- **7.5 Böckenholt 2012 (IRTree)** [설계] — 응답 = 이진 의사결정 트리 분해.
  P(gated)×P(refuse|asked)×P(값|응답)이 우리 옵션벡터 구조와 정확히 일치.
  E00X 후보 설계로 정독. 1.5시간.
